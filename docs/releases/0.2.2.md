- 等待原生更新结果期间，每 5 秒读取一次本地主进程状态；漏收完成通知时也能恢复正确提示。

本地状态回查不会访问更新服务器、重复下载或自动安装。下载和重启安装仍需手动操作。
兼容 Claude++ 0.3.4 及更新版本；Claude++ 0.3.6 同时修复了当前 Claude 设置页漏收主进程广播的原因。
